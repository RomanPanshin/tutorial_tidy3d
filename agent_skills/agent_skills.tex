    \section{Using tidy3d's Official Agent Skill: FlexAgent
MCP}\label{using-tidy3ds-official-agent-skill-flexagent-mcp}

\texttt{tidy3d\_101} and \texttt{charge\_solver} showed you how to build
simulations by hand. This tutorial shows a faster path: Flexcompute
already ships an official AI integration for tidy3d, called
\textbf{FlexAgent MCP}. It turns a coding agent into a physics-aware
tidy3d assistant --- no custom skill-writing required. Every command
below runs for real, so you see the actual output, not a mockup.

    \subsection{What is a coding agent?}\label{what-is-a-coding-agent}

A coding agent is a program that reads a prompt, writes code, runs it,
reads the result, and repeats until the task is done. It lives in your
terminal and edits your project files directly, instead of you
copy-pasting from a chat window.

Two widely used ones:

\begin{itemize}
\tightlist
\item
  \textbf{Claude Code} (Anthropic) --- the \texttt{claude} command
\item
  \textbf{Codex CLI} (OpenAI) --- the \texttt{codex} command
\end{itemize}

Both work the same way from a user's point of view: you type a request
in plain English, the agent plans, edits files, and runs commands.

    \subsection{What is FlexAgent MCP?}\label{what-is-flexagent-mcp}

FlexAgent MCP is Flexcompute's own MCP (Model Context Protocol) server
for tidy3d. Unlike a generic coding agent, it understands tidy3d's API
and electromagnetic-simulation concepts directly, and it can search and
fetch the real tidy3d documentation instead of guessing. It ships two
ways:

\begin{itemize}
\tightlist
\item
  \textbf{Bundled} --- inside the official Tidy3D extensions for Cursor
  and VS Code. Install the extension and FlexAgent is configured
  automatically, rules included.
\item
  \textbf{Standalone} --- as an MCP server, \texttt{tidy3d-mcp}, that
  you register with any MCP-compatible client, including \texttt{claude}
  and \texttt{codex}. That's the path this tutorial uses.
\end{itemize}

    \begin{Verbatim}[commandchars=\\\{\}]
Here's a simple Tidy3D FDTD setup for a silicon strip waveguide (0.5 µm × 0.22
µm × 10 µm), with silicon modeled as a lossless medium of index 3.47:

```python
import numpy as np
import tidy3d as td

\# --- Waveguide geometry (um) ---
wg\_width = 0.5
wg\_height = 0.22
wg\_length = 10.0

\# --- Materials ---
n\_si = 3.47
si = td.Medium(permittivity=n\_si**2, name="Si")
sio2 = td.Medium(permittivity=1.44**2, name="SiO2")  \# oxide cladding/substrate

\# --- Wavelength / frequency setup ---
wavelength = 1.55
freq0 = td.C\_0 / wavelength
fwidth = freq0 / 10
run\_time = 5e-13

\# --- Structures ---
waveguide = td.Structure(
    geometry=td.Box(
        center=(0, 0, 0),
        size=(wg\_length, wg\_width, wg\_height),
    ),
    medium=si,
)

\# --- Source: mode source injecting the fundamental TE mode ---
mode\_spec = td.ModeSpec(num\_modes=1, target\_neff=n\_si)

source = td.ModeSource(
    center=(-wg\_length / 2 + 1, 0, 0),
    size=(0, 3 * wg\_width, 3 * wg\_height),
    source\_time=td.GaussianPulse(freq0=freq0, fwidth=fwidth),
    direction="+",
    mode\_spec=mode\_spec,
    mode\_index=0,
)

\# --- Monitors ---
mode\_monitor = td.ModeMonitor(
    center=(wg\_length / 2 - 1, 0, 0),
    size=(0, 3 * wg\_width, 3 * wg\_height),
    freqs=[freq0],
    mode\_spec=mode\_spec,
    name="mode\_monitor",
)

field\_monitor = td.FieldMonitor(
    center=(0, 0, 0),
    size=(td.inf, td.inf, 0),
    freqs=[freq0],
    name="field\_xy",
)

\# --- Simulation domain ---
sim = td.Simulation(
    center=(0, 0, 0),
    size=(wg\_length, 2.5, 2.0),
    grid\_spec=td.GridSpec.auto(min\_steps\_per\_wvl=15, wavelength=wavelength),
    structures=[waveguide],
    sources=[source],
    monitors=[mode\_monitor, field\_monitor],
    run\_time=run\_time,
    boundary\_spec=td.BoundarySpec.all\_sides(boundary=td.PML()),
    medium=sio2,  \# background medium (oxide cladding)
    symmetry=(0, -1, 1),  \# exploit TE mode symmetry to speed up the simulation
)

\# --- Visualize the setup (optional) ---
\# sim.plot(z=0)
\# sim.plot(y=0)

\# --- Submit to Tidy3D solver (requires API key / account) ---
\# from tidy3d import web
\# job = web.Job(simulation=sim, task\_name="si\_strip\_waveguide")
\# sim\_data = job.run(path="data/sim\_data.hdf5")
```

Notes:
- The waveguide is oriented along `x` (propagation direction), 10 µm long, 0.5
µm wide (`y`), 0.22 µm thick (`z`).
- `symmetry=(0, -1, 1)` assumes a fundamental TE mode and roughly halves compute
cost — remove it if you want to capture non-symmetric modes.
- The `web.Job` submission is commented out since you'd need an active Tidy3D
account/API key to actually run it.
    \end{Verbatim}

    Both answers came from the real \texttt{tidy3d-mcp} server, not from the
model's own (possibly outdated) memory of the API --- that's the point
of registering it.

    \subsection{One step further:

FlexAgent covers tidy3d itself. For everything else an agent does day to

it. A reasonable default: FlexAgent for tidy3d domain knowledge,
superskills for general workflow.
